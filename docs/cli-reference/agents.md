# geenii agents

List and inspect configured agents.

## Synopsis

```
geenii agents <command>
```

## Commands

### list

```
geenii agents list
```

List all configured and loaded agents.

### inspect

```
geenii agents inspect <NAME>
```

Show the full configuration of a named agent, including name, description,
label, model, model parameters, tools, skills, and system instructions.
